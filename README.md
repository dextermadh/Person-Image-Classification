# 👤 Person Image Classification Model

This repository contains a **Person Image Classification** project built using **Python**, **NumPy**, **Pandas**, **Scikit-learn**, **Matplotlib**, **Seaborn** and **OpenCV**. The goal of this model is to classify images of individuals into respective classes based on visual features extracted from the dataset.

## 📂 Dataset

The dataset used in this project consists of labeled images of different individuals and is hosted on Google Drive.

🔗 [Download Dataset from Google Drive](https://drive.google.com/drive/folders/1u3JTM71gS9NHE8--q41MbPOue3bDofbw?usp=sharing)

> **Note:** Make sure to download and extract the dataset into a folder named `dataset/` within the root directory of the project.

## 🛠️ Technologies Used

- Python 3
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- OpenCV (cv2)

## 🧠 Model Overview

- Image data is read using OpenCV.
- Preprocessing includes resizing, grayscale conversion, and flattening.
- Labels are extracted from folder names.
- The dataset is split into training and testing sets.
- A machine learning model (e.g., SVM or KNN) is trained using Scikit-learn.
- Performance is evaluated using accuracy and a classification report.
